# Matrix-Operations-C

A command-line matrix operations program written in C.

## Features

* Matrix addition (`+`)
* Matrix subtraction (`-`)
* Matrix multiplication (`*`)
* Matrix transpose (`T`)
* Supports matrices up to 10 × 10
* Checks whether addition and subtraction are possible
* Checks whether matrix multiplication is possible
* Allows the result to be used as a new Matrix A
* Allows new matrices to be entered
* Quit option (`q`)

## Requirements

* C compiler such as GCC
* Windows, Linux, or another operating system with a C compiler

## How to Run

Compile the program:

```bash
gcc matrix_operations.c -o matrix_operations
```

Run the program:

```bash
./matrix_operations
```

On Windows:

```bash
matrix_operations.exe
```

## Project File

* `matrix_operations.c` — Main C source code for matrix operations.
